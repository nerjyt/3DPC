# Верстак ПК

Конфигуратор компьютера: выбираешь корпус и комплектующие, модель в 3D собирается на глазах, проверяется совместимость и считается цена. Всё написано на Python (сервер) и обычном JavaScript в браузере (3D на three.js).

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export VERSTAK_CONTACT="you@example.com"               # Windows: set VERSTAK_CONTACT=you@example.com
python run.py
```

Открой http://127.0.0.1:8000. Админка с ценами: http://127.0.0.1:8000/admin.

Токен для входа в админку сервер создаёт при первом запуске и кладёт в `data/admin_token.txt`. Свой токен можно задать переменной `VERSTAK_ADMIN_TOKEN`.

Тесты: `python -m pytest -q`. Для теста сверки правил нужен Node.js, без него он пропускается.

## Что умеет

- 3D-модель: вращение, приближение, прозрачная стенка, разборка на части, подписи деталей и подсветка RGB.
- Режим «Осмотр»: выбираешь деталь, камера подлетает к ней, остальное убирается, на детали стоят номера, справа список «что есть что» (вентиляторы, крышка процессора, ключ сокета, контакты, разъёмы). Клик по номеру и по строке подсвечивают друг друга.
- Проверка совместимости: сокет, тип и число модулей памяти, форм-фактор платы, длина видеокарты, высота кулера, радиатор СЖО, мощность блока питания, наличие картинки без видеокарты.
- Готовые сборки, список деталей для копирования, ссылка на сборку (`/?build=…`).
- Цены из российских магазинов и ручной ввод через админку.

## Откуда берутся цены

DNS я не подключал. Сайт закрыт защитой от ботов, а обход такой защиты я не делаю. Если вставить в админку ссылку на DNS, сборщик попробует один раз по правилам, а при блокировке или капче остановится и поставит сайт на паузу. Работают другие магазины, и цены решаются тремя уровнями:

1. **Ручной ввод и CSV** (`/admin`). Самый надёжный путь. Скачай шаблон, впиши цены и загрузи.
2. **Сборщик по ссылкам.** Для каждой детали в админке указываешь адрес страницы товара. Сборщик читает цену из разметки страницы (JSON-LD, microdata, meta).
3. **Ориентир.** Если свежих цен нет, показывается ориентировочная цена из каталога, и в интерфейсе это написано.

Из свежих цен берётся минимальная среди тех, что в наличии. Цена вне диапазона 0,3–3× от ориентира отбрасывается как ошибка разбора. Цена с магазина считается свежей 72 часа, ручная 30 дней.

Как сборщик ведёт себя на чужих сайтах:

- перед каждой страницей читает `robots.txt` (с `*`, `$` и правилом самого длинного совпадения) и не заходит туда, куда нельзя;
- представляется честно: `VerstakPriceBot/1.0` и твой контакт из `VERSTAK_CONTACT`;
- не чаще одного запроса в 6 секунд на сайт;
- при 403/429, капче или странице проверки не повторяет запросы и ставит этот сайт на паузу;
- не ходит на внутренние адреса (защита от SSRF).

Что важно знать:

- `robots.txt` разрешает или запрещает автоматические запросы, но не заменяет условия использования сайта. Прежде чем включать сборщик для постоянной работы, прочитай условия магазина. Если они запрещают автоматический сбор, используй ручной ввод или CSV.
- Состояние на момент сборки проекта (проверялось по `robots.txt`): у Ситилинка ограничений на страницы товаров не было, у XCOM закрыты поисковые адреса, у ОнлайнТрейда закрыты страницы `/item`, поэтому сборщик их пропускает, у Регарда `robots.txt` прочитать не удалось. Это может поменяться.
- Живой сбор цен я не мог проверить из своей среды: оттуда нет доступа к магазинам. Разбор страниц, `robots.txt`, паузы и защита покрыты тестами на заглушках. На твоём компьютере проверь один-два товара в админке и посмотри статус источника.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `VERSTAK_CONTACT` | не задан | контакт в `User-Agent` сборщика, чтобы магазин мог с тобой связаться |
| `VERSTAK_ADMIN_TOKEN` | создаётся в `data/` | токен админки, передаётся в заголовке `X-Admin-Token` |
| `VERSTAK_MIN_DELAY` | `6` | пауза между запросами к одному сайту, секунды |
| `VERSTAK_REFRESH_HOURS` | `12` | как часто фоновый сборщик обходит источники |
| `VERSTAK_AUTO_REFRESH` | `1` | `0` выключает фоновое обновление |
| `VERSTAK_WEB_MAX_AGE_HOURS` | `72` | сколько часов цена с сайта считается свежей |
| `VERSTAK_DATA` | `./data` | папка с базой и токеном |
| `VERSTAK_DB` | `data/verstak.db` | путь к базе SQLite |
| `HOST`, `PORT` | `127.0.0.1`, `8000` | адрес сервера |

Если выставляешь сервер в интернет, поставь перед ним HTTPS-прокси (nginx, Caddy) и задай свой `VERSTAK_ADMIN_TOKEN`.

## Устройство

```
app/            сервер на FastAPI
  catalog_data.py   детали: характеристики, размеры, ориентировочные цены
  compat.py         правила совместимости (эталон)
  prices.py         сборщик цен, robots.txt, ручные цены, CSV
  seed.py           файл цен data/prices.csv для статического сайта
  db.py, main.py    SQLite и API
static/         страница
  js/rules.js       те же правила для мгновенной реакции в браузере
  js/engine3d.js    3D-модели и осмотр
  js/app.js         интерфейс
  admin.html        админка цен
tests/          pytest, включая сверку rules.js и compat.py
tools/build_static.py   сборка сайта без сервера (папка или один файл)
tools/export_prices.py  файл цен для такого сайта (из базы сервера или пустой шаблон)
.github/workflows/pages.yml  автопубликация на GitHub Pages
```

Правила совместимости записаны дважды: на Python и на JS. Тест `tests/test_parity.py` гоняет через оба варианта тысячи сборок и требует одинаковый текст. Меняешь правило, меняй в обоих файлах.

Чтобы добавить деталь, допиши её в `app/catalog_data.py` по образцу соседних. Для видеокарты, кулера и корпуса нужны размеры: по ним строится модель.

## Бесплатный хостинг

Сайт почти целиком работает в браузере: совместимость считает `rules.js`, 3D рисует three.js. Серверу нужны только цены, админка и короткие ссылки. Поэтому самый надёжный бесплатный вариант такой: **собрать сайт в статическую папку и выложить на статический хостинг**. Он не засыпает, не просит карту и не теряет данные при перезапуске.

Что в таком сайте есть: 3D, осмотр деталей, совместимость, готовые сборки, список для копирования, цены из твоего файла, кнопка «Поделиться» (выбор кладётся прямо в ссылку: `?b=…&c=white`). Чего нет: админки, сборщика цен и базы. Они остаются на твоём компьютере, откуда магазины открываются как у обычного покупателя.

### Цены на статическом сайте

Цены лежат в файле `data/prices.csv` и вшиваются в страницу при сборке. Два способа получить файл:

```bash
# 1. Руками, без сервера: шаблон со всеми деталями, открой в Excel и впиши цены
python tools/export_prices.py --template
#    колонки: part_id; price; store; url; in_stock; updated; name. Нужны part_id, price и updated (дата, когда смотрел цену).
#    Пустые цены пропускаются. Кодировка UTF-8 или Windows-1251, разделитель ; , или табуляция.

# 2. Из админки: запусти сервер (python run.py), обнови цены в /admin, выгрузи
python tools/export_prices.py
```

Дальше собери и проверь локально:

```bash
python tools/build_static.py          # dist/site
python -m http.server -d dist/site    # http://localhost:8000
```

Сборка предупредит, если цена не из каталога, не похожа на правду (вне 0,3–3× от ориентира), без даты или старше 30 дней. Такие строки в сайт не попадают, а посетитель всегда видит дату обновления рядом с ценами.

### Публикация

**Вариант А: GitHub Pages, обновляется само.**

1. Создай публичный репозиторий (на бесплатном тарифе Pages работает только с публичными) и залей проект. Файл `data/prices.csv` лежит в репозитории, токен админки и база в него не попадают (`.gitignore`).
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Любой пуш в `main` запускает `.github/workflows/pages.yml`: прогоняются тесты, собирается сайт, он публикуется на `https://<имя>.github.io/<репозиторий>/`.
4. Чтобы обновить цены: выгрузи новый `data/prices.csv`, сделай коммит и пуш.

**Вариант Б: перетащить папку.** Запусти `python tools/build_static.py` и загрузи папку `dist/site` в Cloudflare Pages (Direct Upload) или в Netlify Drop. Репозиторий не нужен. Для Cloudflare Pages сразу выбирай Direct Upload: проект, созданный через git, потом нельзя перевести на загрузку папкой.

Условия бесплатных тарифов (проверялись в октябре 2026, могут меняться):

| Хостинг | Лимиты |
|---|---|
| [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) | сайт до 1 ГБ, трафик 100 ГБ в месяц (мягкий лимит), 10 сборок в час, репозиторий публичный |
| [Cloudflare Pages](https://vorobeoffai.ru/knowledge/cloudflare-pages-besplatnyi-hosting-iz-github/) | 500 публикаций в месяц, до 20 000 файлов, файл до 25 МБ, трафик без ограничений |
| [Netlify, Vercel](https://blog.fillikam.com/guides/kak-vylozhit-sayt-besplatno/) | по 100 ГБ трафика в месяц, на Vercel свой домен только на платном тарифе |

Доступность из России я не проверял, это зависит от провайдера посетителя. Открой готовый адрес с телефона и из домашней сети, прежде чем раздавать ссылку.

Свой домен: на всех четырёх можно подключить, но сам домен (например, `.ru`) платный. Бесплатный адрес вида `имя.github.io` или `имя.pages.dev` работает сразу.

### А запустить сам сервер бесплатно?

Можно, но с оговорками. Например, [Render](https://render.com/docs/free): бесплатный веб-сервис засыпает через 15 минут без запросов и просыпается около минуты, а локальные файлы стираются при каждом перезапуске и выходе из сна. Значит, база с ценами и ссылками на сборки будет пропадать, а с зарубежного адреса российские магазины могут отдавать капчу или блокировать запросы. Для сайта с российскими ценами это плохой вариант. Если нужен именно работающий сервер, выбирай платный VPS с постоянным диском.

## Демо одним файлом

```bash
python tools/build_static.py --single dist/verstak-demo.html
```

Один HTML-файл с ориентировочными ценами (или ценами из `data/prices.csv`). Three.js подгружается с CDN, поэтому нужен интернет. Кнопки «Поделиться» в нём нет.

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/catalog` | детали и актуальные цены |
| POST | `/api/check` | проверка совместимости выбора |
| POST / GET | `/api/builds`, `/api/builds/{id}` | сохранить и открыть сборку |
| GET | `/api/health` | проверка живости |
| * | `/api/admin/*` | управление ценами, нужен `X-Admin-Token` |
